## 2. 成品模块（外购整件）

| 模块 | 选型 | 理由 | 状态 |
|---|---|---|---|
| 射频（首版） | **E01-ML01DP5**（亿佰特） | 正规渠道防假芯片；Radio HAL 抽象 | ✅ |
| 射频（升级候选） | E01-2G4M27D | 距离升级路径；**⚠ 待核对：与 DP5 引脚/尺寸一致性**，画封装前以官方规格书实测 | ⚠ |
| IMU | MPU6050 暂定（候选 ICM-42688-P，噪声低 5×、2KB FIFO） | 引脚兼容；**PCB 插拔座，拔插即换** | ✅ |

| 摇杆 | 万向回中带线轴承 5k 电位器 ×2 | 低成本；霍尔摇杆为后期 rev，软件全复用 | ✅ |
| 电位器旋钮 | ×2 | ADS7830 CH4–5 | ✅ |
| 按键/拨杆 | 轻触×14 + 拨杆×4 + 电源拨动×1 | 型号随面板结构定 | 待定 |
| 喇叭 | 16Ω 0.5–1W | MAX98357A 驱动 | 待定 |
| 震动马达 | 200mA 级 | 事件反馈 | 待定 |
| Type-C 母座 | 16/24Pin，CC 支持 PD | CH224K + 原生 USB 数据 | 待定 |
| 电池+座 | 18650×2 **串联 2S** + 座 | buck 降压纹波小、电流余量足（对比见 yuj-core/docs/hardware.md §3） | ✅ |

## 3. 采购注意事项（防假芯片）

| 渠道规定 | 说明 |
|---|---|
| 射频模块 | **只买亿佰特官方渠道**；淘宝杂牌 nRF24 假芯片泛滥（SI24R1/XN297 克隆，功率虚标、杂散） |
| IMU 模块 | 正规渠道；PCB 插拔座隔离，坏件可换 |
| STM32F103 | C8T6 假货重灾区——必要时选 CBT6/兼容厂（如 CKS）并在 BOM 标注 |
| ESP32-S3 模组 | 乐鑫官方/代理 |
| 到货检验 | 新批次先上开发板冒烟测试（收发/读 ID），再上整机板 |

## 4. 封装核对流程（画 PCB 前必走）

1. 下载**官方规格书**（不是店铺图）存 `docs/datasheet/`
2. 实物测量引脚间距/板长/天线座位置
3. 与封装库逐一核对，差异记入本文 ⚠ 待核对项
4. 当前挂账：E01-ML01DP5 vs E01-2G4M27D 尺寸核对

## 5. 明确不做的事

| 项 | 结论 |
|---|---|
| 接收机模拟电压输出 | 不做——市面 signal 全是数字 PWM/编码信号 |
| 图传集成进遥控终端主板 | 不做——独立子系统，仅结构/连接器预留 |
| 遥控端触摸屏 | 第一版不做，全按键导航 |
