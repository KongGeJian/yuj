# 元器件与成品模块选型库（parts.md）

> 记录选型决策：选了什么、为什么、待核对什么。两大节：**元器件**（需贴片的 IC/阻容/连接器）与**成品模块**（外购整件）。
> 待核对项以 **⚠ 待核对** 标出，画封装/下单前先解决。

## 三、明确不做的事

| 项 | 结论 |
|---|---|
| 接收机模拟电压输出 | **不做**——市面接收机 signal 全是数字 PWM/编码信号，不存在模拟电压输出形态 |
| 图传集成进遥控终端主板 | **不做**——图传独立子系统，仅结构/连接器预留 |
| 遥控端触摸屏 | 第一版不做，全按键导航 |
