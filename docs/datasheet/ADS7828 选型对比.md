# ADS7828 选型对比 - ADS7828 选型对比.md

> 2026-11-01 定稿记录。结论：**ADS7828**（¥21.04 原装 TSSOP-16）。落选方案完整保留，供未来复核或升级参考。
> 规格书：[ADS7828.pdf](ADS7828.pdf)（TI 官方）、[MCP3208.pdf](MCP3208.pdf)（Microchip 官方，落选者档案）。

## 1. 需求还原

| 需求 | 数值/口径 | 来源 |
|---|---|---|
| 采样对象 | 摇杆 2×2 轴**独立高采样**（必外置）；旋钮 ×2 低优（外置有富余则外置） | 本次讨论 |
| 采样率 | 链路 250Hz → 每轴 ≥250SPS，合计 ≥1kSPS | protocol.md |
| 精度 | 12bit；低噪声优先 | 项目目标（含飞机场景） |
| 核心噪声问题 | buck（MP1584）纹波调制读数 → 需**外部 REF 接摇杆轨做比率测量**（纹波同除抵消） | 需求推导 |
| 供电 | 3.3V 单电源 | 电源树 |

## 2. 内置 vs 外置（为什么外置）

| ESP32-S3 内置 ADC 的硬伤 | 说明 |
|---|---|
| 基准不可外接 | 以内部基准测绝对电压，电位器挂在 buck 轨上，**纹波直接调制读数**（±1–2%），无法做比率测量 |
| 有效精度 ~9–10bit | 非线性集中在量程两端，可校但封顶 |
| ADC2 与 WiFi 冲突 | 阶段三启用 WiFi 后 ADC2 不可用，模拟量全挤 ADC1 |

→ 精度优先 + 飞机场景 + 阶段三 WiFi，**外置 ADC 定案**。

## 3. 候选对比

| 型号 | 位数/通道 | 接口 | 外部 REF | 判定 |
|---|---|---|---|---|
| **ADS7828**（TI，¥21.04 原装 TSSOP-16） | 12bit / 8ch | I²C | ✅ REF IN/REFOUT 复用脚 | **✅ 定稿** |
| MCP3208（微芯，¥13.1 原装 SOIC-16） | 12bit / 8ch | SPI | ✅ VREF | 次选（SPI 共享 + 假货风险） |
| ADC128S102（TI） | 12bit / 8ch | SPI | ✅ | 落选：与 MCP3208 同构、共享 SPI3，带宽严重过剩 |
| MCP3204 | 12bit / 4ch | SPI | ✅ | 落选：4ch 装不下旋钮 → 双采样体系，架构不干净 |
| ADS7830（TI） | **8bit** / 8ch | I²C | ✅ | 落选：位数不达标（256 级，飞机精细操纵不够）；此前文档误记为 12bit/SPI 已纠正 |
| ADS7841（TI） | 12bit / 4ch | SPI | ✅ REF± | 落选：老料、SSOP-20、价高无优势 |
| ADS1015（TI） | 12bit / 4ch | I²C | **❌ 基准内置** | 落选：无外置 REF 纹波问题原样回来；4ch 分摊 825SPS/ch 零余量 |

## 4. 决策依据（ADS7828 vs MCP3208 终局）

| 维度 | ADS7828 ✅ | MCP3208 |
|---|---|---|
| 总线 | 挂现有 I²C，**SPI3 维持 nRF24 专用** | 共享 SPI3，射频路径引入总线仲裁 |
| 布局 | 低速开漏，可布摇杆模拟区本地 | SPI 走线跨板到射频区，时钟耦合模拟区 |
| 假货风险 | 冷门料基本无仿 | 热门克隆目标（本次原装渠道，**再补货风险回来**） |
| 封装/手焊 | TSSOP-16 0.65mm 脚距（拖焊+助焊剂可行） | SOIC-16 1.27mm 脚距（轻松） |
| 价差 | +¥8 | — |

**结论**：链路实时性（SPI3 独占）+ 模拟区本地化 + 假货风险归零，胜过 ¥8 价差与手焊便利。

## 5. 定稿设计要点

| 项 | 规定 |
|---|---|
| 通道分配 | CH0–3 摇杆 4 轴 / CH4–5 旋钮 / CH6–7 模拟扳机预留（全外置） |
| 基准 | REF 脚接摇杆电位器供电轨（比率测量，纹波抵消） |
| 采样率 | 50kSPS 能力 vs 1kSPS 需求，余量充足；I²C 400kHz 档即够 |
| S3 内置 ADC | 仅电池电压监测（精度要求低） |
| 源阻抗 | 摇杆 5k（模组自带）；旋钮 **10k**（面板主流规格；5k/10k 误差均被校准消除，非决策项） |
| 前端滤波 | 每个模拟输入脚 100nF 对地（滤耦合噪声 + SAR 25pF 采样电荷库） |
