## 2. 充电链路选型对比

### 2.1 PD 诱骗

| 候选 | 协议线 | 判定 |
|---|---|---|
| **CH224K**（¥1，SOT23-6/ESSOP-10） | **CC 线**——与 D± 数据物理隔离 | ✅ 定稿；**默认 9V（CFG1=6.8kΩ，手机快充主力档），换 24kΩ 切 12V**——单一 PCB 设计换电阻切档（悬空=20V 会打坏后级，电阻**必焊**）；PG 脚开漏→TCA9555 #2 内部上拉（兼做 5V/9V 判据）；9V vs 12V：9V 兼容面广（18W 小头满速），12V 恒压尾段压差裕量大，电流才是充电时间瓶颈 → **9V 默认** |
| FS312BL（丝印312b） 诱骗器模块（用户手持） | CC | ❌ 弃用：按键/跳线选档的不确定性 + 整机要的是死档芯片 |

### 2.2 充电主 IC

| 候选 | 拓扑 | 5V 输入 | 9V 输入（PD 默认档） | 判定 |
|---|---|---|---|---|
| **TP5100**（QFN16，¥2） | buck 降压 2A | ❌ 停机（机制：**输入低于电池电压即停机**，规格书 p7，漏电 1µA） | ✅ 2A 快充 | ✅ 定稿（快充路）；内置防倒灌/PWR_ON− 电源切换脚（PMOS 方案备用）/红绿 LED/CHRG 状态脚→S3；输入 5–18V；2A=0.57C/0.8C（双电池规格）均 <1C |
| **IP2326**（QFN24，¥2） | boost 升压 1.2A | ✅（4.5–5V 工作，耐压 25V） | OVP 停充（NC 默认 8.75V，不损坏） | ✅ 定稿（5V 备充路）；**DP/DM 悬空**（放弃 D± 协议申请——避让 S3 USB 数据），纯 5V→8.4V 升压；CON_SEL 悬空=2 串；**VBATM/VBAT_GND 接串联中点/地 = 充电均衡唯一职责**（VCBON 单节到位开启内部均衡 MOS，RCB 设电流） |
| IP2326F 模块 | 同上 | — | — | 原型期验证用，整机上芯片 |
| BQ25798 + STUSB4500 | 真 buck-boost 5A + I²C 可编程 PD | ✅ | ✅ | ❌ 首版不用：¥40–60（5 倍价）+ QFN29 手焊 + I²C 配置开发；能力大半用不上（5A/OTG/MPPT/PPS）。**记为二版升级路径** |
| BQ24179 + PD 控制器 | 降规格版 | ✅ | ✅ | ❌ 同上，折中价仍 3 倍 |

### 2.3 双路互锁（方案 B 核心）

```text
Type-C VBUS ──CH224K(CC 协商)──▶ 9V ──┬─▶ TP5100 ──▶ 2A 快充 ──┐
              （无 PD 协议时 = 5V）      │   （5V 时欠压不启动）        ├─▶ 电池 P+
                                       └─────────────────────────┘   ▲
              5V 时 ──IP2326──▶ 8.4V/1.2A 慢充 ───────────────────────┘
                    （9V/12V 时 OVP 8.75V 停充，不损坏）
```

- **互锁零门控**：TP5100 欠压 ⇄ IP2326 过压，任一输入电压只有一路活跃，省比较器/PMOS 切换电路；
- **D± 归属**：CH224K 走 CC、IP2326 的 DP/DM 悬空、S3 独占 D±——三协议互不抢线。

### 2.4 四场景行为定稿

| 插入 | 行为 |
|---|---|
| PD 快充头（协商 9V） | TP5100 2A 快充（关机/开机均可，充电支路在开关前；实际受 9V/2A 头 18W 限制 ~1.8A，待实测标定） |
| 普通充电器（5V/2A） | IP2326 升压 ~1.2A 慢充 |
| 电脑 USB（5V） | 慢充 + 数据/下载同时可用 |
| 仅电池 | 分压 ADC（开关后）→ 屏显电量条 + 低电报警 |

## 3. BMS 选型

| 候选 | 判定 |
|---|---|
| **无均衡保护板，模块电路整体移植上板** | ✅ 定稿：均衡职责唯一归 IP2326（充电时硬件自动执行）→ BMS 只管过充/过放/过流（放电安全）；移植元件少 4–6 个、少一路中点分压网络；故障域更小（IP2326 坏只失均衡，保护独立）；**路线 = 买 2S 保护板金样机逆向照搬**（阈值厂商已调好）；⚠ 到手量过放断输出（6.0V）验证 |
| 带均衡保护板 + IP2326 VBATM 悬空 | 备选：两均衡并行不冲突（若购物车已购带均衡版可直接用，只是移植多几个件） |
| IP2326 均衡独立扛（无 BMS） | ❌ 保护 IC 仍必须有（放电过流/过放/短路场景 IP2326 管不到） |

**均衡维护习惯（零固件）**：TP5100 快充时 IP2326 停机不均衡 → **每月插一次普通 5V 头、关机充**（均衡硬件自动执行）；提醒增强（PG 判 5V/9V + 30 天提示）挂阶段二。

## 4. 供电轨选型

### 4.1 主轨 3.3V / 5V（buck）

| 候选 | 判定 |
|---|---|
| **MP1584EN ×2**（5V / 3.3V） | ✅ 定稿 |
| AMS1117 / LM7805 | ❌ 线性损耗物理不可行：7.4→3.3V × 400mA = 1.64W（SOT-223 热保护）；7805 低电时跌出规格。线性仅适用「小压差小电流」场合 |
| 接收机 LDO | **HOLD**（接收机整机板延后；口径 ≥300mA、压差 ≤0.4V，AMS1117 压差 1.1V 出局） |

### 4.2 屏面板 3.0V

| 候选 | 判定 |
|---|---|
| **RT9193-3.0**（3.3V→3.0V，SOT-23-5） | ✅ 定稿：面板逻辑实测 mA 级，压差富余（此前「贴线」判断是在电流未知时的保守） |
| AMS1117-3.0 | ❌ 压差 1.1V > 输入差 0.3V，数学死 |
| ME6211C30 | 平替可（同 SOT-23-5 低压差），采购看货源 |
| 5V→3.0V LDO | ❌ 压差 2V 纯浪费热 + 逻辑域远离主控电平 |
| SPI 电平转换 | **不需要**：3.3V VOH 2.64V > ST7789 VIH 2.1V；TE 输出 3.0V > S3 VIH 2.475V，双向均有 ≥0.5V 裕量 |

### 4.3 背光（4-LED 并联 VF 3.0V/80mA，不做调光）

| 候选 | 判定 |
|---|---|
| **3.3V + 3.9Ω + S8050 + GPIO 开关** | ✅ 定稿（方案 A）：电流 (3.3−VF−0.1)/3.9Ω ≈ 81mA@VF3.0；**VF 到货实测，偏 2.8V 换 5.1Ω / 偏 3.2V 换 2.2Ω**（0805 随手换）；S8050 基极 1kΩ 接 GPIO（不做 PWM、不做电位器——保「背光超时」设置项 + 免机械磨损件） |
| RT9193-3.0 恒压直驱 | ❌ 恒压驱指数负载：VF 3.1V 不亮、VF 2.9V 电流失控翻倍——**电阻的本质是恒流化，LDO 替代不了** |
| 3.3V + 恒流 IC | ❌ 物理不成立：线性恒流需 ≥1.1V 自身压差，3.3−3.0=0.3V 不够 |
| 5V + NSI45020 恒流管 | 可行（±5% 免调校），被否：+¥4 + 5V 支路换「免一次实测调阻」不值 |
| 5V + 串电阻 | 可行的保守案，被否：已选更简的 3.3V 版 |

**VF 漂移知识**（本节决策依据）：VF 是 LED 内部 PN 结压降（非外部节点电压），漂移源 = 制造批次 ±0.1–0.2V、温度 −2mV/°C、老化缓升；指数伏安特性（60mV/倍频）使无电阻约束的电流不可控。

## 5. USB / 下载链路

| 项 | 定稿 |
|---|---|
| 物理口 | **Type-C ×1**：D±（S3 原生 USB-Serial-JTAG：下载/调试/阶段二模拟器）+ CC（CH224K 协商）+ VBUS（充电），三路物理隔离 |
| 外围 | USBLC6-2SC6 紧贴座子；D± 等长 ≤1mm；VBUS 走线 ≥1mm（2A+）；CH224K 紧贴座子 CC 短走 |
| 电脑侧 | 普通数据线（⚠ 避开仅充电线）；Win10+/macOS/Linux 免驱；esptool 通常自动进下载模式 |
| **RST 轻触键 ×1** | ✅ 新增（库存微动开关，挂 EN 网络）：**与屏 RESX 同网**（S3 复位时屏同步复位，状态机不残留；分网则需驱动发 SWRESET 兜底且 RESX 不得悬空）；+ BOOT = 救援进下载；软件兜底 = 开机 3s BOOT 长按菜单；**布局与功能键分开**（防误触） |
| 桥接芯片（CH343 等） | ❌ 不用：S3 内置 USB-Serial-JTAG 已覆盖，开发板双口是兼容惯性 |
| UART0 测试焊盘 | 预留（GPIO43/44）：USB 被固件关死时的救援口 |
