# PCB 设计要点 - pcb.md

> 单一真源：两端共性规则 + 各板硬件详设（引脚分配 / 布局 / 电源 / 接口）。选型依据见 [parts.md](parts.md)；数据手册在 [datasheet/](datasheet/)（文件名 = 型号）。

## 1. 两端共性规则

| 要点 | 说明 |
|---|---|
| 射频布局 | E01 模块**远离 buck/充电电路**，放板边，天线区**净空**（无铜无走线） |
| 天线位预留 | **SMA 转接位 + 焊接天线双封装**，换模块不动板 |
| 测试焊盘 | 首版关键节点留测试焊盘：电池电压、5V、3.3V 轨、SPI 总线 |
| 电源纹波 | nRF24 PA 峰值处就近放储能电容；buck 按 datasheet 最小热回路布局 |
| ESD | Type-C/暴露接口加 ESD 保护；焊接调试佩戴防静电腕带 |

**调试与安全**：

| 项 | 规定 |
|---|---|
| 上电前 | 万用表查各轨间阻抗，再上电（测试焊盘即检查点） |
| 锂电 | 必须过 BMS（均衡+过流+过放） |
| failsafe | 实机测试前必须先验证失控行为（关遥控器 → 油门归预设） |
| 射频法规 | 功率/频段遵守所在地无线电规定；测试优先低功率档 |

## 2. 遥控终端板（yuj-core）

### 2.1 输入件与去向

| 输入件 | 数量 | 类型 | 去向 |
|---|---|---|---|
| 电源开关（SK-22F03-G12） | 1 | 拨动 | **机械串入电池主回路**（⚠ 触点电流待核对；DPDT 并脚分流；软关机由按键长按承担） |
| 摇杆（万向回中带线轴承，5k 电位器） | 2×4轴 | 模拟 | **ADS7828** CH0–3（REF 接摇杆轨，比率测量）；**经 1.25mm 6P 卧贴母座转接**（双联电位器 6 线） |
| 电位器旋钮（RV0932 B103 长柄立式） | 2 | 模拟 | ADS7828 CH4–5 |
| （预留：模拟扳机 L2/R2） | (2) | 模拟 | **ADS7828 CH6–7 已预留** |
| 左十字键 / 右侧 XYAB（无声开关 6×6×5 SMD） | 4+4 | 数字 | PCA9555 |
| 肩键 L1 L2 R1 R2（带灯轻触 6×6×9 卧式，绿2蓝2） | 4 | 数字（首版） | PCA9555 #1；**LED 与按键机械联动，按下导通即亮，不占任何 IO 口** |
| 摇臂拨杆（3脚直插，**2-3-3-2 布局定稿**） | 2+2 | 数字 | PCA9555 **#2**：杆1/4（2档）各 1 口=灯/喇叭；杆2/3（3档）各 2 口=模式切换/绞盘差速锁，共 6 口 |
| View / Menu | 2 | 数字 | **S3 直连 GPIO**（中断直读，菜单导航响应最快） |

- **PCA9555 ×2（0x20/0x21）**：#1 = 十字4 + XYAB4 + 肩键4 = 12 口，余 4 口备用；#2 = 拨杆 6 口，**余 10 口备用**。拨杆全按 3 档双输入布线（2 档杆第二输入脚不焊），未来升级全 3 档零改版。
- **肩键 LED 硬件联动**：带灯轻触开关 LED 与触点同键体机械联动（按下=触点导通+LED 亮），**LED 串限流电阻直接挂 3.3V 轨，零 IO 消耗、零软件逻辑**。
- **摇杆零点自修正（软件）**：上电采集 N 秒静止样本取均值为零点（期间提示手离杆/禁止输出）；运行中一阶低通慢速跟踪缓漂；两端死区可配。

### 2.2 引脚预算与总线分配

**总线分配（定稿）**：SPI2=LCD 高速；SPI3=**nRF24 专用**；I²C=PCA9555 + MPU6050 + ADS7828 共享。LCD 刷屏是长 DMA，nRF24 IRQ 是延迟敏感短事务，分 SPI 总线是实时性关键；ADS7828 走 I²C（地址可选，与 PCA9555/MPU6050 无冲突），不占 SPI——选型依据见 [datasheet/ADS7828 选型对比.md](datasheet/ADS7828%20选型对比.md)。

预算（S3-WROOM-1 N16R8；GPIO35–37 被 PSRAM 占用，可用 GPIO0–21+38–48，扣 USB 后约 28 个实用脚）：

| 功能块 | 占用 | 备注 |
|---|---|---|
| USB D−/D+ | 2 | GPIO19/20 原生 USB |
| SPI2：LCD（SCK/MOSI/CS/DC/背光） | 5 | MISO 省、RST 并 EN |
| SPI3：总线 3 + nRF24 CS/CE/IRQ | 6 | 射频专用，IRQ 中断 |
| I2C：PCA9555 ×2 + MPU6050 + ADS7828 | 2 | 四器件共享（地址 0x20/0x21、0x68、0x48 段，无冲突） |
| I2S：MAX98357A（DIN/BCLK/LRC） | 3 | SD 脚硬件接电平省 1 |
| 震动马达 PWM | 1 | MOS 驱动 |
| 电池电压 ADC | 1 | S3 内置 ADC 分压（监控精度要求低） |
| View / Menu | 2 | |
| 充电状态输入（CH224K PG/BMS） | 1 | 屏显充电图标 |
| Boot（GPIO0 复用） | 1 | 兼用户键 |
| **合计** | **~23–26** | **余量 2–5 脚** |

**结论**：引脚满足但余量不奢侈——新按键走扩展芯片；重要扩展（图传）走 USB/连接器，不占 GPIO。

### 2.3 电源树与充电

```text
18650×2 串联 2S(7.4V) ──电源拨动开关──┬─▶ buck#1 5V  ─▶ 屏背光 / 对外供电预留(图传)
   └ BMS(均衡+过流+过放)            └─▶ buck#2 3.3V ─▶ S3/nRF24/ADS7828/PCA9555/MPU6050/MAX98357
                                       └─▶ 屏面板 VCC 3.0V（方案待电源梳理：独立小 buck/LDO 分档）
Type-C ──CH224K PD诱骗(9V)──▶ 2S 8.4V CC/CV 充电
   └ D−/D+ ──▶ S3 原生 USB（数据；插电脑不充电）
分压电阻 ─▶ ADC ─▶ 电池电压遥测（屏显电量条+低电报警，遥测系统第一个本机数据）
```

> 屏背光（LED-A/K，4-LED 并联 80mA@3.0V）挂 5V 轨经限流/分档电阻——3.3V 轨带不动 80mA@3.0V 且要避背光电流纹波灌射频。

| 设计点 | 说明 |
|---|---|
| 2S 串联 vs 并联 | buck 降压纹波小、PA 峰值电流余量足；并联需 buck-boost 且升压纹波灌射频——**串联定稿** |
| 2S 电池回路 | 电源拨动开关**机械串入主回路**；BMS 均衡走线满足充电电流 |
| 充电 | Type-C PD 协商 9V（CH224K）→ 普通 2S 8.4V CC/CV；插电脑仅数据 |
| 电流裕量 | 3.3V 轨 ≥500mA，同时为升级 E01-2G4M27D（更高功率）预留 |

### 2.4 反馈与其余外设

| 单元/外设 | 选型/驱动 | 说明 |
|---|---|---|
| 震动马达（φ12×18.5 圆柱 3.3V 60mA，已有） | GPIO PWM + MOS | 低电报警、失控提示、游戏；60mA 运转但堵转更高，**仍需 MOS 驱动** |
| 扬声器（8Ω 1W，20×30mm 椭圆，厚 3.5） | **MAX98357A 成品模块**（I2S 接入） | 提示音、游戏音效、WAV；模块 Vin 宽压 2.5–5.5V → **板上走线预留 5V/3.3V 0Ω 选焊**（3.3V≈0.7W / 5V 1.8W） |
| 显示 | **T240B7-C12-36** 2.4" IPS（240×320，ST7789，12P 插接） | esp_lcd 驱动抽象，换屏只改驱动配置；无触摸；**面板 VCC 供电 3.0V**（规格书 Typ 2.75V，3.3V 为 Max——见电源梳理待办）；TE 脚接 MCU 做防撕裂同步 |
| IMU | **GY-521 模块**插拔座 | 引脚兼容 ICM-42688-P（候选），拔插即换；**远离震动马达**；⚠ 新批次芯片 WHO_AM_I≠0x68，驱动不得硬校验 ID |
| 射频 | E01-ML01DP5 | Radio HAL；预留 E01-2G4M27D（**直插型封装兼容已核对**，SMA+焊接天线双封装，换模块不动板） |

震动+音频统一走 `feedback_event(id)` 事件服务分发。

| 要点 | 说明 |
|---|---|
| USB | CC1/CC2 接 CH224K；D−/D+ 直连 S3 GPIO19/20，**等长 + ESD 保护** |

## 3. 接收机板（yuj-rx）

### 3.1 双模供电

```text
模式A(舵机轨取电)                     模式B(电池直供，大功率)
信号排针 VCC ──肖特基──┐            2S电池专用接口 ──反接二极管+自恢复保险──▶ BEC(buck 5V)
 (4.0–5.5V)            ├────── 肖特基合流 ──▶ LDO 3.3V ──▶ nRF24/STM32
                       ┘
```

| 设计点 | 说明 |
|---|---|
| 模式A | 舵机轨 VCC 兼作电源输入（标准接收机行为：插任一通道排针 V/G 供电，全板 VCC 连通） |
| 合流 | 两路肖特基合流进 LDO，**可同时接互不倒灌**（调试场景） |
| **红线：BEC 不反灌舵机针** | 模式B 下 BEC 只供内部 3.3V，大功率场景舵机由外部 BEC 各自供电——**2S 直入 5V 舵机 = 烧毁**；合流二极管方向在原理图评审专项检查 |
| BEC / LDO | BEC 宽输入 buck（Vin≥17V 裕量，5V/1A）；**LDO 选型搁置**（压差需 ≤0.4V，电源电路统一梳理时定，候选见 [parts.md](parts.md)） |

### 3.2 LED 与绑定键

| LED | 颜色 | 语义 |
|---|---|---|
| PWR | 绿 | 常亮=上电 |
| LINK | 蓝 | 慢闪(1Hz)=搜寻 / 常亮=链路锁定 / 快闪(5Hz)=绑定模式 / 双闪循环=failsafe 生效中 |

绑定键：独立按键，**靠近 LED**；上电 5s 内按住进配对。

### 3.3 输出接口

| 接口 | 规格 |
|---|---|
| PWM 排针 | **8× 三线组（GND/VCC/SIG）**，SIG 靠边；1000–2000µs，50/333Hz 可配 |
| 串口×2 | UART1：飞控（CRSF/SBUS 类，双向）；UART2：GPS 等模块（遥测回传，链路分片轮播） |
| 天线 | E01 模块自带（SMA/IPEX），净空见 §1 |
