# PCB 设计要点

## 通用（两端）

| 要点 | 说明 |
|---|---|
| 射频模块布局 | E01 模块**远离 buck/充电电路**，天线区**净空**（无铜、无走线）；模块优先放板边 |
| 天线位预留 | **SMA 转接位 + PCB 天线/焊接天线双封装**，换模块不动板 |
| 测试焊盘 | 首版关键节点留测试焊盘：电池电压、5V、3.3V 轨、SPI 总线（返板调试不飞线刮铜） |
| 假芯片防护 | 射频/IMU 选正规渠道成品模块 + **插拔座**隔离（IMU 插拔座已定） |
| 电源纹波 | nRF24 PA 峰值电流处就近放储能电容；buck 布局按 datasheet 最小热回路 |

## 遥控终端（yuj-core 专属细节见模块文档）

| 要点 | 说明 |
|---|---|
| 2S 电池回路 | 电源拨动开关**机械串入电池主回路**；BMS 均衡走线满足充电电流 |
| SPI 分总线 | **SPI2=LCD 高速总线，SPI3=nRF24+ADS7830 低速总线**——避免刷屏 DMA 排队卡射频 IRQ 读取 |
| USB | Type-C CC1/CC2 接 CH224K；D−/D+ 直连 S3 GPIO19/20，走线等长、ESD 保护 |
| IMU 插拔座 | MPU6050 模块座（引脚兼容 ICM-42688-P），座子远离震动马达 |

## 接收机（yuj-rx）

| 要点 | 说明 |
|---|---|
| **红字警告：BEC 不反灌舵机针** | 大功率模式（2S 直供）下 BEC 只供内部 3.3V，**不得反灌舵机 VCC 排针**——2S 直入 5V 舵机 = 烧毁。合流二极管方向在原理图评审时专项检查 |
| 舵机轨供电 | 全板 VCC 连通，插任一通道排针的 V/G 即可供电（标准接收机行为） |
| 双输入合流 | 舵机轨 + 电池专用接口经**肖特基二极管合流**进 LDO，两路可同接互不倒灌 |
| 绑定键 | 独立按键座子，靠近 LED |
| PWM 输出排针 | 8×（GND/VCC/SIG）三线一组，SIG 靠边便于插杜邦/舵机线 |
