# pcb.md — PCB 设计要点

## 1. 通用（两端）

| 要点 | 说明 |
|---|---|
| 射频布局 | E01 模块**远离 buck/充电电路**，放板边，天线区**净空**（无铜无走线） |
| 天线位预留 | **SMA 转接位 + 焊接天线双封装**，换模块不动板 |
| 测试焊盘 | 首版关键节点留测试焊盘：电池电压、5V、3.3V 轨、SPI 总线 |
| 电源纹波 | nRF24 PA 峰值处就近放储能电容；buck 按 datasheet 最小热回路布局 |
| ESD | Type-C/暴露接口加 ESD 保护；焊接调试佩戴防静电腕带 |

## 2. 遥控终端（细节见 yuj-core/docs/hardware.md）

| 要点 | 说明 |
|---|---|
| 2S 电池回路 | 电源拨动开关**机械串入主回路**；BMS 均衡走线满足充电电流 |
| SPI 分总线 | **SPI2=LCD 高速；SPI3=nRF24+ADS7830**——刷屏 DMA 不得阻塞射频 IRQ 读取 |
| USB | CC1/CC2 接 CH224K；D−/D+ 直连 S3 GPIO19/20，等长 + ESD 保护 |
| IMU 插拔座 | MPU6050 模块座（兼容 ICM-42688-P），远离震动马达 |

## 3. 接收机（细节见 yuj-rx/docs/hardware.md）

| 要点 | 说明 |
|---|---|
| **红线：BEC 不反灌舵机针** | 2S 直供模式下 BEC 只供内部 3.3V；**2S 直入 5V 舵机 = 烧毁**。合流二极管方向在原理图评审专项检查 |
| 舵机轨供电 | 全板 VCC 连通，插任一通道排针 V/G 即供电 |
| 双输入合流 | 舵机轨 + 电池接口经肖特基合流进 LDO，可同接互不倒灌 |
| 绑定键 | 独立按键，靠近 LED |
| PWM 排针 | 8×（GND/VCC/SIG）三线一组，SIG 靠边 |

## 4. 调试与安全

| 项 | 规定 |
|---|---|
| 上电前 | 万用表查各轨间阻抗，再上电（测试焊盘即检查点） |
| 锂电 | 必须过 BMS（均衡+过流+过放） |
| failsafe | 实机测试前必须先验证失控行为（关遥控器 → 油门归预设） |
| 射频法规 | 功率/频段遵守所在地无线电规定；测试优先低功率档 |
