# PCB 设计要点 - pcb.md

> 单一真源：两端共性规则 + 各板硬件详设（引脚分配 / 布局 / 电源 / 接口）。选型依据见 [parts.md](parts.md)；数据手册在 [datasheet/](datasheet/)（文件名 = 型号）。硬件需求以 [PRD-stage-1.md](prd/PRD-stage-1.md) §2.3 为准。

## 1. 共性规则

| 要点 | 说明 |
|---|---|
| 射频布局 | E01 模块**远离 buck/充电电路**，放板边，天线区**净空**（无铜无走线） |
| 天线位预留 | **SMA 转接位 + 焊接天线双封装**，换模块不动板 |
| 测试焊盘 | 首版关键节点留测试焊盘：电池电压、5V、3.3V 轨、SPI 总线 |
| 电源纹波 | nRF24 PA 峰值处就近放储能电容；buck 按 datasheet 最小热回路布局 |
| ESD | Type-C D± 加 ESD 保护：**USBLC6-2SC6 ×1**（VCC 接 +3V3——**勿接 VBUS**，PD 9V 超 VRWM 5V 会导通烧毁，2026-11-09 勘误）；VBUS 不加（后级 CH224K/TP5100/IP2326 自带耐压 + 就近电容）；焊接调试佩戴防静电腕带 |

**调试与安全**：

| 项 | 规定 |
|---|---|
| 上电前 | 万用表查各轨间阻抗，再上电（测试焊盘即检查点） |
| 锂电 | 必须过 BMS（过充+过放+过流；**均衡由 IP2326 充电时执行**，见 §2.3） |
| failsafe | 实机测试前必须先验证失控行为（关遥控器 → 油门归预设） |
| 射频法规 | 功率/频段遵守所在地无线电规定；测试优先低功率档 |

## 2. 遥控终端板（yuj-core）

### 2.1 输入件与去向

| 输入件 | 数量 | 类型 | 去向 |
|---|---|---|---|
| 电源开关（SK-22F03-G12） | 1 | 拨动 | **机械串入电池主回路**（3A 触点、双通道并联，主回路 ~0.5A 裕量充足）；**软关机不做（定稿）**——控制终端无需待机，机械开关断电即关机、零漏电 |
| 摇杆（万向回中带线轴承，5k 电位器） | 2×4轴 | 模拟 | **ADS7828** CH0–3（REF 接摇杆轨，比率测量）；**经 1.25mm 6P 卧贴母座转接**（双联电位器 6 线） |
| 电位器旋钮（RV0932 B103 长柄立式） | 2 | 模拟 | ADS7828 CH4–5 |
| （预留：模拟扳机 L2/R2） | (2) | 模拟 | **ADS7828 CH6–7 已预留** |
| 左十字键 / 右侧 XYAB（无声开关 6×6×5 SMD） | 4+4 | 数字 | TCA9555 #1 |
| 肩键 L1 L2 R1 R2（带灯轻触 6×6×9 卧式，绿2蓝2） | 4 | 数字（首版） | TCA9555 #1；**LED 与按键机械联动，按下导通即亮，不占任何 IO 口**；⚠ 蓝 LED VF≈2.8–3.2V 挂 3.3V 轨压差仅 0.1–0.5V——亮度可能偏弱、限流电阻与绿键异值，**到货实测配阻** |
| 摇臂拨杆（3脚直插，**2-3-3-2 布局定稿**） | 2+2 | 数字 | TCA9555 **#2**：杆1/4（2档）各 1 口=灯/喇叭；杆2/3（3档）各 2 口=模式切换/绞盘差速锁，共 6 口 |
| View / Menu | 2 | 数字 | **S3 直连 GPIO**（中断直读，菜单导航响应最快） |

- **TCA9555 ×2（0x20/0x21）**：#1 = 十字4 + XYAB4 + 肩键4 = 12 口（按键高频组，250Hz 轮询），余 4 口备用；#2 = 拨杆 6 口 + **慢信号 4 口（背光开关 / TP5100 CHRG / IP2326 BAT_STAT / CH224K PG，延迟不敏感，低频轮询）**，另 2 口为 2 档杆升级预留，**余 4 口备用**。拨杆全按 3 档双输入布线（2 档杆第二输入脚不焊），未来升级全 3 档零改版。
- **INT 不接（定稿）**：全部轮询（按键 ≤4ms 延迟足够），不占 S3 脚；TCA9555 INT 开漏可线或，未来确有需要再回收 1 脚。
- **按键零硬件消抖（2026-11-08 定稿）**：全部软件消抖——轮询组连续 2–3 次读数确认（8–12ms 窗口）、View/Menu 时间戳滤波；不加 RC 电容（16 键×104 纯冗余，且 τ 依赖未实测的 TCA 内部上拉值）。仅未来外接长线按键才考虑 RC。
- **肩键 LED 硬件联动**：带灯轻触开关 LED 与触点同键体机械联动（按下=触点导通+LED 亮），**LED 串限流电阻直接挂 3.3V 轨，零 IO 消耗、零软件逻辑**。
- **摇杆零点自修正（软件）**：上电采集 N 秒静止样本取均值为零点（期间提示手离杆/禁止输出）；运行中一阶低通慢速跟踪缓漂；两端死区可配。

### 2.2 引脚预算与总线分配

**总线分配（定稿）**：SPI2=LCD 高速；SPI3=**nRF24 专用**；**I²C 拆双路——I2C0=ADS7828+MPU6050（采样总线），I2C1=TCA9555×2（IO 总线）**。分 SPI 原因不变（LCD 长 DMA 与 nRF24 短事务隔离）；**I²C 拆分原因**：ADS7828 逐通道寻址 + MPU6050 高频读单总线估算占 40–50%，且 SAR 采样会被 IO 轮询阻塞——拆分后互不干扰（S3 双硬件 I²C 控制器，仅 +2 脚）；选型依据见 [datasheet/ADC采样选型对比.md](datasheet/ADC采样选型对比.md)。

预算（S3-WROOM-1 N16R8；GPIO35–37 被 PSRAM 占用，可用 GPIO0–21+38–48，扣 USB 后约 28 个实用脚）：

| 功能块 | 占用 | 备注 |
|---|---|---|
| USB D−/D+ | 2 | GPIO19/20 原生 USB |
| SPI2：LCD（SCK/MOSI/CS/DC/TE） | 5 | MISO 省、RST 并 EN；背光开关移 TCA9555 #2；SCK=IO12/MOSI=IO11 **压在 IO MUX 原生脚（FSPICLK/FSPID）→ 80MHz 满速**（2026-11-07 核对） |
| SPI3：总线 3 + nRF24 CS/CE/IRQ | 6 | 射频专用，IRQ 中断；SCK/MOSI/MISO=IO3/4/5 走 GPIO 矩阵（**上限 ~40MHz**）——nRF24 SPI 上限 10MHz 富余 4×，够用；⚠ **勿在 SPI3 挂高速设备**（SD 卡等） |
| I2C0：ADS7828 + MPU6050 | 2 | 采样总线（0x48 段、0x68） |
| I2C1：TCA9555 ×2 | 2 | IO 总线（0x20/0x21；含背光与充电状态慢信号） |
| I2S：MAX98357A（DIN/BCLK/LRC） | 3 | SD 脚硬件接电平省 1 |
| 震动马达 PWM | 1 | MOS 驱动 |
| 电池电压 ADC | 1 | S3 内置 ADC 分压（监控精度要求低） |
| View / Menu | 2 | 直连（中断直读，导航响应最快） |
| 充电状态输入 | 0 | 移 TCA9555 #2：**TP5100 CHRG + IP2326 BAT_STAT 双路充电状态都感知** + CH224K PG（PD 协商指示；**5V/9V 路径判别以 CHRG 活动为准**——快充旁路跳线短接后 PG 仍会拉低，不再单独代表 9V） |
| Boot（GPIO0 复用） | 1 | 兼用户键 |
| UART 扩展排针（GPIO43/44） | 2 | **兼 UART0 救援焊盘一排两用**：固件正常=UART1 扩展（图传/调试），USB 关死=外接 USB-TTL |
| **合计** | **27** | **余量 ~2 脚** |

**结论**：拆 I²C 双路 + UART 排针预留后余量收窄至 **~2 脚**——**新按键/慢信号一律走 TCA9555**；重要扩展（图传）走 **UART 排针/连接器**（USB D± 已被数据独占，不走 USB）。

### 2.3 电源网络与充电（全链路定稿）

**充电链路**（Type-C 单口，D± 数据 / CC 协议 / VBUS 充电三路物理隔离；选型依据见 [datasheet/电源选型对比.md](datasheet/电源选型对比.md)）：

```text
Type-C ─┬─ D± ──USBLC6-2SC6──▶ S3 GPIO19/20（原生 USB-Serial-JTAG：下载/调试/模拟器）
        ├─ CC ──▶ CH224K（PD 协商；CFG1=6.8kΩ 默认 9V，换 24kΩ 切 12V；PG 开漏→TCA9555 #2）
        └─ VBUS ─┬─▶[协商成功 9V]──▶ TP5100（buck 2A 快充；CHRG 状态脚→TCA9555 #2）──┐
                 │    5V 时输入低于电池电压→停机（漏电1µA，防倒灌内置）
                 └─▶[未协商 =5V ]──▶ IP2326（升压 8.4V/1.2A 慢充；BAT_STAT 状态脚→TCA9555 #2）──┤
                      9V 时 OVP(8.75V) 停机不损坏；DP/DM 悬空不抢数据线
                                                                   ▼
18650×2 串联 2S ──▶ BMS 板载（无均衡保护型，模块电路整体移植）◀─ 电池 P+（充电支路）
   电池盒 SMD 上板，中点 = PCB 网络──▶ IP2326 VBATM（充电均衡唯一职责）
   └─▶ SK-22F03 开关（3A 双通道并联）──▶ 系统输入节点
```

**供电轨**：

```text
系统输入 ─┬─▶ MP1584 #1 → 5V   ─▶ 图传预留 / 功放模块 0Ω 选焊位（默认 3.3V 档）
          ├─▶ MP1584 #2 → 3.3V ─▶ S3/nRF24/ADS7828/TCA9555×2/MPU6050/屏背光
          │     ├─▶ RT9193-3.0 → 3.0V ─▶ 屏面板 VCC（逻辑，mA 级）
          │     └─▶ 3.9Ω ── LED-A ─(屏内4LED并联)─ LED-K ── S8050 ── GND
          │           TCA9555 #2 ──1kΩ──▶ 8050 基极（纯开关无调光、轮询控制；基极配 10kΩ
          │           下拉——TCA 上电输入态内部 100k 上拉仅 µA 级，防背光微亮，由固件点亮；
          │           VF 实测后微调阻值）
          └─▶ 分压电阻 ─▶ S3 ADC（开关后：关机零耗电）
```

**四场景行为**：

| 场景 | 充电 | 系统 | 指示 |
|---|---|---|---|
| PD 头（9V）+ 开关 ON | TP5100 2A 快充 | 边充边用 | 屏显充电图标（CHRG/BAT_STAT→TCA9555 #2）+ 板载红绿 LED |
| PD 头 + 开关 OFF | 2A 快充 | 无电 | 板载红（充）/绿（满）LED |
| 普通 5V 头 / 电脑 USB | IP2326 ~1.2A 慢充 | 电脑连接时数据+下载正常 | **IP2326 LED 脚（pin6）接板载指示**——TP5100 此路停机，红绿 LED 不反映 5V 慢充 |
| 仅电池 | — | 正常运行 | 屏显电量条+低电报警（早于 BMS 6.0V 过放） |

**设计红线**：

| # | 规则 | 依据 |
|---|---|---|
| 1 | **CH224K CFG1 电阻必焊**——悬空=请求 20V 打坏 TP5100（输入上限 18V） | CH224 规格书 p3 |
| 2 | **充电支路接开关前**（关机可充）；**分压采样接开关后**（关机零漏电） | 使用场景 |
| 3 | **电池负极只进 BMS B-，系统地 = P-**——充放电流必须过保护 MOS | BMS 原理 |
| 4 | **IP2326 DP/DM 悬空**（放弃 D± 协议申请，保 S3 数据独占） | 单口架构 |
| 5 | D± 等长 ≤1mm；VBUS 走线 ≥1mm（2A+）；USBLC6 紧贴座子；CH224K 紧贴 CC 短走 | USB/充电完整性 |
| 6 | **均衡维护习惯**：TP5100 快充时 IP2326 停机不均衡——**每月慢充一次**（5V 头，或**短接快充旁路跳线后用 PD 头**）；IP2326 均衡硬件自动执行，零固件；提醒功能挂阶段二 | IP2326 规格书 p10 |
| 7 | 3.3V 轨 ≥500mA 裕量（nRF24 PA 峰值 + E01-2G4M27D 升级预留） | 射频性能 |
| 8 | MP1584/TP5100/IP2326 按 datasheet 最小热回路布局；功率电感远离 E01 天线区 | 纹波→射频 |

**其余设计点**：

| 设计点 | 说明 |
|---|---|
| 2S 串联 vs 并联 | buck 降压纹波小、PA 峰值电流余量足；并联需 buck-boost 且升压纹波灌射频——**串联定稿** |
| 电池 | 双规格通吃：3500mAh(3C)/2500mAh(12C)，TP5100 2A = 0.57C/0.8C 均 <1C 安全 |
| BMS 板载 | 无均衡保护板**模块电路整体移植**（保护 IC+功率 MOS 原样照搬，金样机逆向）；均衡职责唯一归 IP2326（VBATM/VBAT_GND 接中点/地 + RCB 配套）。**4 颗 IRFR3704Z 为功能必需**（充/放各一对背靠背，单颗只能单向阻断，非并联冗余）；**跨 MOS 的 100k 泄放电阻（B−↔P−）保留**——datasheet 典型图无此件，作用：防 P− 浮空、稳定 CS 基准、充电器检测保障、残压泄放（2026-11-10 抄板核对） |
| 主控复位 | **RST 轻触键挂 EN 网络**（与屏 RESX 同网：S3 复位时屏同步复位，状态机不残留；不占 GPIO）；RST 用库存微动开关，**布局与功能键分开**（防误触）；+BOOT（GPIO0 复用）= 援进下载救 |
| UART0 救援焊盘 | GPIO43/44 引测试焊盘：USB 被固件关死时外接 USB-TTL 恢复 |
| **快充旁路跳线（2026-11-10 新增）** | **CFG1→VDD 双焊盘跳线**：**断开=默认 9V 快充**；短接=CH224K 请求 5V（快充关闭、仅 IP2326 慢充，C-to-C 线 5V 充电不受影响——**禁止改为断 CH224K 供电/CC**：Rd 消失会导致 C-to-C 无 VBUS）。兼作「PD 头慢充均衡维护」手段。固件零改动：充电状态以 CHRG/BAT_STAT 判，**PG 不再单独区分 5V/9V** |
| 充电 IC 升级路径 | BQ25798+STUSB4500（buck-boost 5A/I²C/OTG）——二版备选，见选型对比文档 |

### 2.5 布局要点

**外观布局定稿**：[core-外观布局.drawio](core-外观布局.drawio)（正面/背面/顶面/底面，虚线=背面元件在正视图的投影）。PCB 元件摆放服从外观布局；内部件（RST/BOOT 等）不外露，必要时外壳预留针孔。

| 要点 | 说明 |
|---|---|
| 外观对应 | 天线顶部中央（E01 板边净空）；**MPU6050 在 PCB 正面中央**（外观图背面视图的投影标注处）——与震动马达对角远离；电池×2 背面左右对称（底面凸起助握）；扬声器/震动马达背面 |
| USB | CC1/CC2 接 CH224K（紧贴座子短走）；D−/D+ 直连 S3 GPIO19/20，**等长 ≤1mm + USBLC6 紧贴座子**；VBUS ≥1mm 走线（2A+）；**座子按外观布局在底面** |
| IMU 焊位 | 远离震动马达（MPU6050 正面中央 vs 马达背面，板厚隔离+对角） |
| 充电链路 | CH224K/TP5100/IP2326 功率回路紧凑布局；电感远离 E01 天线区 |
| RST/BOOT 键 | RST 挂 EN 网（库存微动开关），**PCB 板上不外露**（救援时开壳/外壳预留针孔）；BOOT 复用 GPIO0 用户键 |

## 3. 接收机板（yuj-rx）

### 3.1 双模供电

```text
模式A(舵机轨取电)                     模式B(电池直供，大功率)
信号排针 VCC ──肖特基──┐            2S电池专用接口 ──反接二极管+自恢复保险──▶ BEC(buck 5V)
 (4.0–5.5V)            ├────── 肖特基合流 ──▶ LDO 3.3V ──▶ nRF24/STM32
                       ┘
```

| 设计点 | 说明 |
|---|---|
| 模式A | 舵机轨 VCC 兼作电源输入（标准接收机行为：插任一通道排针 V/G 供电，全板 VCC 连通） |
| 合流 | 两路肖特基合流进 LDO，**可同时接互不倒灌**（调试场景） |
| **红线：BEC 不反灌舵机针** | 模式B 下 BEC 只供内部 3.3V，大功率场景舵机由外部 BEC 各自供电——**2S 直入 5V 舵机 = 烧毁**；合流二极管方向在原理图评审专项检查 |
| BEC / LDO | BEC 宽输入 buck（Vin≥17V 裕量，5V/1A）；**LDO 选型搁置**（压差需 ≤0.4V，电源电路统一梳理时定，候选见 [parts.md](parts.md)） |

### 3.2 LED 与绑定键

| LED | 颜色 | 语义 |
|---|---|---|
| PWR | 绿 | 常亮=上电 |
| LINK | 蓝 | 慢闪(1Hz)=搜寻 / 常亮=链路锁定 / 快闪(5Hz)=绑定模式 / 双闪循环=failsafe 生效中 |

绑定键：独立按键，**靠近 LED**；上电 5s 内按住进配对。

### 3.3 输出接口

| 接口 | 规格 |
|---|---|
| PWM 排针 | **8× 三线组（GND/VCC/SIG）**，SIG 靠边；1000–2000µs，50/333Hz 可配 |
| 串口×2 | UART1：飞控（CRSF/SBUS 类，双向）；UART2：GPS 等模块（遥测回传，链路分片轮播） |
| 天线 | E01 模块自带（SMA/IPEX），净空见 §1 |
