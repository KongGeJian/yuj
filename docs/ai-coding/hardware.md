# 硬件规范

## 采购（防假芯片）

| 规定 | 说明 |
|---|---|
| 射频模块 | **只买亿佰特官方渠道**（E01-ML01DP5）；淘宝杂牌 nRF24 假芯片泛滥（SI24R1/XN297 克隆，功率虚标、杂散辐射） |
| IMU 模块 | 正规渠道 MPU6050/ICM-42688-P 模块；PCB 用**插拔座**隔离，坏件可换 |
| 主控 | STM32F103 C8T6 假货重灾区——**必要时选 CBT6/兼容厂（如 CKS）并标注**；ESP32-S3 模组选乐鑫官方/代理 |
| 到货检验 | 新批次模块先上开发板跑冒烟测试（收发/读 ID），再上整机板 |

## 封装核对流程（画 PCB 前必走）

1. 下载**官方规格书**（不是店铺图）
2. 实物测量引脚间距/板长/天线座位置
3. 与封装库逐一核对，差异记录进 `docs/parts.md` ⚠ 待核对项
4. 当前挂账项：E01-ML01DP5 vs E01-2G4M27D 尺寸核对

## 安全（红线）

| 项 | 规定 |
|---|---|
| 锂电 | 2S 18650 必须过 BMS（均衡+过流+过放）；首版板测试焊点见 `pcb.md`，上电前万用表查轨间阻抗 |
| 接收机供电 | **BEC 不得反灌舵机 VCC 针**（2S 直入 5V 舵机 = 烧毁），合流二极管方向原理图评审专项检查 |
| 射频法规 | 发射功率/频段遵守所在地无线电规定；测试优先低功率档 |
| failsafe | 实机测试前必须先验证失控保护行为（关遥控器 → 油门归预设） |
| ESD | 焊接/调试佩戴防静电腕带；Type-C/暴露接口加 ESD 保护 |
