## 1. P0（必须改）

### ~~P0-1 TP5100 CHRG 经 LED 上拉到 VBUS，直连 TCA9555~~

> **2026-11-13 复核：已解决。** D3 隔离后，TCA P1_1 只看到二极管阳极；CHRG 空闲时 LED2 从 VBUS 拉高的是 D3 阴极，二极管反偏，TCA 由内部 100K 拉到 3.3V。D3=1N4004 SMA，方向正确（D3-2 A→TCA，D3-1 K→CHRG）。以下原表为 2026-11-12 记录，仅留痕。

| 项 | 内容 |
|---|---|
| live 网表 | `TP5100_CHRG = U3-15(CHRG) + LED2-1(K) + U9-14(TCA P1_1)` |
| 电路 | `VBUS → R9 1K → LED2(A) → LED2(K) → CHRG` |
| 问题 | CHRG 高阻（充满/未插线）时，LED2 从 VBUS 把节点拉起。9V 时约 **7V**，12V 时更高；TCA 输入上限 **5.5V**，绝对最大 6V |
| 方案 | ① 最简：LED2 阳极从 VBUS 改接 **+3V3**（节点最高 3.3V，CHRG 低时 LED 仍亮）；② 保留 VBUS LED，CHRG 经 NPN/电平转换进 TCA；③ TCA 侧 3.3V 钳位 + 串阻。推荐 ① |
| 验证 | 不插线/充满状态测 U9-14 对地，必须 <3.6V |

> `STDBY/LED3` 没进 TCA，只有 LED，暂安全；`CH224_PG = U2-10 + U9-16` 是开漏、无 LED，TCA 内部 100K 上拉到 3.3V，**安全**。`IP2326_BAT_STAT` 见 P1-2。

### ~~P0-2 FM7021DB 与 CB 混用~~

> **2026-11-13 复核：按抄板 BMS 模块接受。** live U7=FM7021DB。**遗留文档项（P2）**：parts.md/PRD 的 6.0V 过放与 DB 2.25V/节（4.5V 组）不一致，需按实际模块更新验收口径。以下原表为 2026-11-12 判断，仅留痕。

| 项 | 内容 |
|---|---|
| live 器件 | U7 = **FM7021DB**（PARTTYPE/Manufacturer Part 都是 DB） |
| 文档 | P2 注释写 `FM7021CB`；parts.md/PRD 要 6.0V 组过放 |
| 规格书 | p1 表：CB 过放 **2.90V/节（5.8V 组）**；DB **2.25V/节（4.5V 组）** |
| 影响 | 若装 DB，电池会放到 4.5V，18650 过放，PRD 验收 #6「早于 BMS 6.0V」不成立 |
| 方案 | BOM/符号/注释统一为 **FM7021CB**（或 NB 2.80V）；到货核对丝印；文档同步 |
