# 系统架构与 UI 设计 - architecture.md

> 硬件/PCB 详设单一真源在 [pcb.md](pcb.md)；协议见 [protocol.md](protocol.md)；选型见 [parts.md](parts.md)。

## 1. 系统总览

**一句话**：ESP32-S3 遥控终端 + STM32F103 接收机，2.4GHz nRF24 架构 TDMA 跳频链路，monorepo 三子项目共享协议库，三阶段演进（基础遥控 → 电脑模拟 → 图传）。

```text
┌──────────── 遥控终端 yuj-core (ESP32-S3 / ESP-IDF+LVGL) ────────────┐
│ 输入: 摇杆2(ADS7828) 旋钮2 │ 按键14+拨杆4(PCA9555×2) │ View/Menu 直连 │
│ 显示: 2.4" SPI IPS(T240B7, 240×320) │ IMU: MPU6050(插拔座,候选ICM-42688) │
│ 反馈: 震动马达 + I2S音频(MAX98357A) │ USB: Type-C 双模式           │
│ 射频: E01-ML01DP5(SPI, Radio HAL, 预留E01-2G4M27D)                │
│ 电源: 2S 18650 + PD诱骗充电(CH224K) → buck 5V/3.3V                │
└──────────────┬─────────────────────────────────────────────────────┘
               │ 2.4GHz TDMA ping-pong, 250Hz, FHSS, 双向遥测
┌──────────────┴───────── 接收机 yuj-rx (STM32F103C8T6) ─────────────┐
│ 射频: E01同款 │ 输出: 8ch PWM(50/333Hz) │ 串口×2: 飞控+GPS回传    │
│ LED×2 │ 绑定键 │ failsafe(500ms可配) │ 电源: 双模输入(见模块文档) │
└─────────────────────────────────────────────────────────────────────┘
```

## 2. 仓库结构与依赖（方案 A）

```text
yuj/
├── docs/          # 跨模块文档（含 datasheet/ 数据手册库、ai-coding/ 总规范）
├── yuj-common/    # 协议库：纯头文件+少量C
├── yuj-core/      # 遥控端固件（ESP-IDF + LVGL）
└── yuj-rx/        # 接收机固件（CMake + arm-none-eabi）
```

| 机制 | 做法 |
|---|---|
| 共享方式 | 源码级相对路径引用 `../yuj-common`（零延迟感知，无包管理） |
| 版本纪律 | `PROTOCOL_VERSION` 宏，两端构建期断言一致 |
| CI 规则 | 动 `yuj-common/` 的 PR 必须双端构建通过 |
| 依赖方向 | 单向 `common ← core/rx`，common 不得反向 include |

## 3. 软件分层

```text
应用层    UI(LVGL) │ 游戏app(注册制) │ USB模式(HID/CDC) │ 模型管理
服务层    输入采集 │ 链路调度 │ 遥测聚合 │ 存储(NVS/迁移) │ 事件反馈(震动+音频)
HAL层     radio │ display(esp_lcd抽象) │ adc(ADS7828) │ io(PCA9555) │ audio(I2S) │ imu
公共库    yuj-common：帧定义/跳频算法/通道字段/CRC/PROTOCOL_VERSION
```

| 扩展点 | 机制 |
|---|---|
| 换射频模块 | Radio HAL 只改驱动参数表（功率档/电流特性） |
| 新游戏 | 一个游戏一个 .c 注册到大厅列表，不侵入核心逻辑 |
| 反馈事件 | `feedback_event(id)` 一路分发到马达 PWM 与 I2S 音频 |

### 3.1 存储与内存规划（模组 N16R8 定稿）

| 分区 | 大小 | 用途 |
|---|---|---|
| bootloader + otadata | ~60KB | |
| ota_0 / ota_1 | 各 3MB | 双分区 OTA（WiFi 无线升级预留） |
| NVS | 96KB | 设置、模型实例、绑定表（schema 版本迁移，升级保留数据） |
| assets (LittleFS) | ~9MB | 字体、WAV 音效、游戏素材、天气图标 |
| coredump | 64KB | 崩溃转储（开发期） |

PSRAM 8MB：LVGL 双帧缓冲（~300KB）+ 游戏画面/大图缓存。

## 4. UI 设计（LVGL）

### 4.1 主界面：双模式

| 模式 | 内容 | 默认 |
|---|---|---|
| **A 通道监视** | 8–16 通道 bar + 底部状态栏（本机电量 / 双向 LQ / 模式） | ✅ |
| **B 遥测仪表** | 电压、信号质量大仪表为主，通道缩小 | |

- **View 长按**切换 A/B；系统设置可改默认模式。
- 本机电量（2S 分压 ADC）、双向 LQ（下行本地统计 / 上行由接收机回传）常驻两模式状态栏。

### 4.2 菜单树

```text
【主界面】A 通道监视(默认) ⇄ B 遥测仪表
│
├─ Menu键 → 【主菜单】
│   ├─ 模型管理 ★核心
│   │   ├─ 当前模型（快捷显示/切换，开机记忆）
│   │   ├─ 新建模型（选模板：越野车/货车/无人机/轮船/坦克/自定义）
│   │   ├─ 模型详情（编号自动分配、可命名、可删）
│   │   └─ 模型设置
│   │       ├─ 通道设置（映射、反向、行程、微调、EXPO曲线）
│   │       ├─ 失控保护（逐通道预设值、触发时间）
│   │       ├─ 输出模式（50/333Hz、SBUS开关）
│   │       └─ 模型专属显示（B模式仪表布局偏好）
│   ├─ 游戏大厅（贪吃蛇/打砖块/2048/俄罗斯方块/飞机大战…）
│   ├─ 模拟练习
│   │   ├─ USB 手柄模式（HID）/ 蓝牙手柄模式（BLE HID）
│   │   ├─ PC 联机（CDC：校准/配置/固件升级上位机）
│   │   └─ 按键映射（ABXY/L1R1 → 遥控按键映射表）
│   ├─ 网络信息（天气预报；预留：WiFi 状态、NTP 时间同步）
│   └─ 系统设置
│       ├─ 校准（摇杆/旋钮零点行程）
│       ├─ 绑定管理（配对、跳频种子、LQ门限报警）
│       ├─ 显示设置（亮度、背光超时、主题、默认主界面模式）
│       ├─ USB模式默认角色
│       ├─ 系统信息（版本、电池、运行时间、LQ、debug）
│       └─ 恢复出厂
└─ View键 → 返回上级 / 长按见交互表
```

**分类要点**：「模板（车型决定默认通道映射）→ 模型实例（具体载具，独立参数）」两级抽象；通道设置/失控保护/输出模式是**每模型不同**的，放模型设置；校准/显示等全局项放系统设置。

### 4.3 按键交互

| 按键 | 短按 | 长按（≥600ms） |
|---|---|---|
| **Menu** | 进入菜单 / 确认 | 无（防误触） |
| **View** | 逐级返回上级 | **全局直回主界面（任何菜单深处）**；主界面时切 A/B |
| 十字↑↓ | 列表导航 / 数值 ±1 | 连续加速（长按 2s 后 ±10） |
| 十字←→ | 页签切换 / 数值快调 | — |
| ABXY | 菜单内：A=确认 Y=返回 | 主界面：X=快捷微调面板、B=静音震动 |
| L1/R1 | 列表翻页 | 主界面：LQ/电压放大视图 |

**三原则**：① View 永远「退」、Menu 永远「进」；② 任何界面 3 键内可达主页；③ 高频操作（切模型/微调）有快捷键直达。

### 4.4 UI 阶段归属

| 菜单项 | 阶段 |
|---|---|
| 模型管理（完整版）、系统设置、A/B 主界面 | 一 |
| 模拟练习（USB HID + CDC）、游戏大厅首 1–2 个 + 音效、蓝牙手柄 | 二 |
| 天气/NTP、游戏扩充 | 三/长期 |

## 5. 主要风险与对策

| 风险 | 对策 |
|---|---|
| nRF24 链路时序/跳频调不通（风险最集中处） | 投整机 PCB 前先开发板验证（250Hz 稳定 + failsafe 可靠）；射频参数全进 Radio HAL 配置表 |
| ~~屏型号未定~~ 已定稿 T240B7（2.4" IPS 350nit） | esp_lcd 驱动抽象层，换屏只改驱动配置 |
| 接收机 F103C8 20KB RAM 紧张 | 协议按 12ch 生效起步；不够升 CBT6/RCT6，架构不变 |
| 假芯片/模块品质 | 正规渠道 + 插拔座隔离（见 [parts.md](parts.md) §3） |
| 单人软硬件双线 | 阶段一「链路验证 + UI 框架」两线并行，返板窗口期写软件 |

## 6. 明确不做的事（项目边界）

| 项 | 结论 |
|---|---|
| 接收机模拟电压输出 | 不做——市面 signal 全是数字 PWM/编码信号 |
| 图传集成进遥控终端主板 | 不做——独立子系统，仅结构/连接器预留 |
| 遥控端触摸屏 | 第一版不做，全按键导航 |
