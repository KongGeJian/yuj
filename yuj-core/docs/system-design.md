## 1. 充电模块（软件）

### 1.1 目标

| 项 | 要求 |
|---|---|
| 电量 | 电池分压 ADC → 电量条/百分比 |
| 慢充 | 电池图标显示 **1 个闪电** |
| 快充 | 电池图标显示 **2 个闪电** |
| 充满/未充电 | 不显示闪电 |
| 异常 | 故障图标/告警，不显示闪电 |

### 1.2 软件可见的硬件能力（接口契约）

| 信号 | 接口 | 有效电平 | 软件语义 |
|---|---|---|---|
| `TP5100_CHRG` | TCA#2 P1_1 | 低 | 快充路径正在充电 |
| `IP2326_LED_SENSE` | TCA#2 P1_2 | 低 | IP2326 LED 亮 = 慢充中；高 = 灭/充满；翻转 = 故障 |
| `CH224_PG` | TCA#2 P1_3 | 低 | PD 协商成功（辅助，不单独判快充） |
| `TP5100_STDBY` | TCA#2 P1_4（可选，当前未接） | 低 | 快充充满；与 CHRG 都高 = 故障/无电池 |
| `BAT_ADC` | S3 GPIO1 / ADC1_CH0 | 模拟 | 电池电压；分压比/校准见 pcb.md §2.3.2 |

- `IP2326_BAT_STAT` 已取消；慢充/充满/故障全部由 IP2326 LED 提供。
- TCA#2 方向：P1_0 输出（背光），P1_1..P1_4 输入；P1_5..P1_7 备用。
- 电平转换、二极管/N-MOS、ADC 分压、TCA 引脚分配：**见 pcb.md §2.3.2**，软件只依赖上表能力。

### 1.3 状态机

```text
CHARGE_NONE ──插 5V──▶ CHARGE_SLOW ──充满──▶ CHARGE_FULL
     │                     │
     └──插 PD 9V/12V──▶ CHARGE_FAST ──充满──▶ CHARGE_FULL
                           │
                      IP LED 闪烁 / CHRG+STDBY 都高
                           ▼
                       CHARGE_FAULT
```

| 状态 | 判据 | UI |
|---|---|---|
| `CHARGE_NONE` | CHRG 高，IP LED 灭，无充电 | 无闪电 |
| `CHARGE_SLOW` | CHRG 高，IP LED 亮 | **1 个闪电** |
| `CHARGE_FAST` | CHRG 低 | **2 个闪电** |
| `CHARGE_FULL` | IP LED 灭 + 电池≈8.3–8.4V；或 STDBY 低 | 无闪电，充满图标 |
| `CHARGE_FAULT` | IP LED 翻转；或 PG 低 + CHRG/STDBY 都高 | 故障图标/告警，无闪电 |

- 优先级：`FAULT` > `FAST` > `SLOW` > `FULL` > `NONE`。
- `FAST` 只看 CHRG，不看 PG：FC_SEL1 短接时 PD 5V 也会拉低 PG，但 CHRG 仍高，应显示 1 个闪电（慢充）。
- 9V/12V 时 IP2326 过压停充，IP LED 灭；只有 TP5100 CHRG 低 → 2 个闪电。
- 5V 时 TP5100 输入低于电池，CHRG 高；IP2326 充电，IP LED 亮 → 1 个闪电。

### 1.4 电量估算

| 项 | 软件做法 |
|---|---|
| 采样 | BAT_ADC 10Hz；中值/EMA 滤波 |
| 换算 | `Vbat = Vadc × K`；K 默认取硬件分压比（见 pcb.md §2.3.2），再乘 NVS 单点校准系数 |
| 校准 | 万用表实测电池电压 vs ADC 码，系数存 NVS，上电加载 |
| 低电 | 警告 **6.4V**、严重 **6.1V**，0.1V 回差；早于 BMS 实际过放点（抄板 FM7021DB 为 4.5V 组） |
| 充电时 | 充电电压被抬高，百分比可保持/做充电补偿；UI 用充电动画，不把瞬时抬压当真实电量 |
| 百分比 | 6.0–8.4V 映射 0–100%（或按 Li-ion OCV 表）；低电时图标变色/震动提示 |

### 1.5 轮询、防抖与故障

- TCA 状态 **50ms 采样、连续 3 次确认**；状态变化才刷新 LVGL。
- IP LED 闪烁按 **1.5s 窗口**判定：稳定亮/灭为正常，窗口内多次翻转判故障。
- 充电状态优先级见 §1.3；故障时停止闪电显示，进入告警。
- 电量与充电状态独立采样：电量 10Hz，充电状态 20Hz（50ms），互不阻塞。

### 1.6 UI 映射（LVGL）

| 软件状态 | 电池图标 |
|---|---|
| `CHARGE_FAST` | **2 个闪电** |
| `CHARGE_SLOW` | **1 个闪电** |
| `CHARGE_FULL` | 无闪电，充满图标 |
| `CHARGE_NONE` | 无闪电 |
| `CHARGE_FAULT` | 故障图标/告警，无闪电 |

- 闪电数量只由状态机决定，不由电流大小/电压高低推断。
- 充电时电量条可显示动画；充满/低电颜色与震动由 `feedback_event` 分发。

### 1.8 软件验证

| 场景 | 期望 |
|---|---|
| 5V 普通充电器 | 1 个闪电；IP LED 亮 |
| PD 9V/12V 快充 | 2 个闪电；CHRG 低 |
| PD 5V（FC_SEL1 短接） | 1 个闪电（CHRG 高、IP LED 亮） |
| 充满 | 无闪电；IP LED 灭；快充路径 STDBY 低（若接） |
| 拔掉充电器 | 无闪电 |
| IP2326 异常 | IP LED 闪烁 → 故障图标 |
| 低电 | 6.4V 警告、6.1V 严重；早于 BMS 实际过放点 |
| ADC 校准 | 6.0/7.2/8.4V 三点实测误差 ≤±0.1V |
