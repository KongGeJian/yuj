# yuj-core 模块规范 - law.md

> 只写本模块增补，总规范见 [../../../docs/ai-coding/law.md](../../../docs/ai-coding/law.md)。

## 1. 任务优先级（FreeRTOS）

| 优先级 | 任务 | 说明 |
|---|---|---|
| 最高 | 射频链路定时（4ms 节拍） | **节拍抖动直接吃 LQ**，独占高优先级 |
| 中 | 输入采集（ADS7828/TCA9555 轮询，≤4ms 与链路同拍） | |
| 低 | LVGL UI 任务 | 刷新让路于实时 |
| 最低 | WiFi/蓝牙/音频等非实时 | 阶段二三功能 |

## 2. 线程与中断

| 规定 | 说明 |
|---|---|
| LVGL 线程安全 | 所有 `lv_*` 调用只在 UI 任务（或持 `lv_lock`）；其他任务经消息队列投递 |
| ISR 只置标志 | nRF24 IRQ 的 ISR 只写环形缓冲/标志，处理放下半部（TCA9555 INT 不接，全轮询） |
| 跨任务数据 | 走消息队列或双缓冲，**禁裸共享变量** |

## 3. 总线分配（硬件定稿，软件遵守）

| 总线 | 挂载 | 理由 |
|---|---|---|
| SPI2 | LCD（esp_lcd，DMA） | 高速刷屏 |
| SPI3 | nRF24（专用） | 射频 IRQ 短事务不被刷屏排队阻塞 |
| I2C0 | ADS7828（ADC）+ MPU6050 | **采样总线**；ADS7828 为 12bit/8ch/I²C 型号 |
| I2C1 | TCA9555 ×2（0x20/0x21） | **IO 总线**——SAR 采样与按键/慢信号轮询互不阻塞 |

## 4. 内存

| 项 | 规定 |
|---|---|
| 实时路径 | 链路任务/ISR 用内部 RAM（`IRAM_ATTR` 显式标注），**禁用 PSRAM** |
| PSRAM（8MB） | LVGL 双帧缓冲、字体、WAV、游戏素材、大图缓存 |

## 5. 存储（NVS）

- 模型实例/绑定表/设置存 NVS，**带 schema 版本号 + 迁移函数**——固件升级必须保留用户已创建的模型（硬性要求）。
- 新持久化键先登记命名空间清单，禁止散落魔法字符串。
