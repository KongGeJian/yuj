# yuj-core 整机硬件详设

> 选型依据与采购注意事项见 [../../docs/parts.md](../../docs/parts.md)；PCB 布局见 [../../docs/pcb.md](../../docs/pcb.md)。

## 1. 输入件与去向

| 输入件 | 数量 | 类型 | 去向 |
|---|---|---|---|
| 电源开关 | 1 | 拨动 | **机械串入电池主回路**（不占 IO；软关机由按键长按承担） |
| 摇杆（万向回中带线轴承，5k 电位器） | 2×4轴 | 模拟 | ADS7830 CH0–3 |
| 电位器旋钮 | 2 | 模拟 | ADS7830 CH4–5 |
| （预留：模拟扳机 L2/R2） | (2) | 模拟 | **ADS7830 CH6–7 已预留** |
| 左十字键 / 右侧 XYAB | 4+4 | 数字 | PCA9555 |
| 肩键 L1 L2 R1 R2 | 4 | 数字（首版） | PCA9555 |
| 拨杆开关 | 4 | 数字 | PCA9555 |
| View / Menu | 2 | 数字 | **S3 直连 GPIO**（中断直读，菜单导航响应最快） |

- PCA9555 16 口全占满；再加按键需扩第二颗或复用 Boot 键（GPIO0）。
- **摇杆零点自修正（软件）**：上电采集 N 秒静止样本取均值为零点（期间提示手离杆/禁止输出）；运行中一阶低通慢速跟踪缓漂；两端死区可配。

## 2. 外设与引脚预算

**总线分配（定稿）**：SPI2=LCD 高速；SPI3=nRF24+ADS7830（独立 CS）。LCD 刷屏是长 DMA，nRF24 IRQ 是延迟敏感短事务，分总线是实时性关键。

预算（S3-WROOM-1 N16R8；GPIO35–37 被 PSRAM 占用，可用 GPIO0–21+38–48，扣 USB 后约 28 个实用脚）：

| 功能块 | 占用 | 备注 |
|---|---|---|
| USB D−/D+ | 2 | GPIO19/20 原生 USB |
| SPI2：LCD（SCK/MOSI/CS/DC/背光） | 5 | MISO 省、RST 并 EN |
| SPI3：总线 3 + nRF24 CS/CE/IRQ + ADC CS | 7 | 配合射频 IRQ 中断 |
| I2C：PCA9555 + MPU6050 | 2 | |
| I2S：MAX98357A（DIN/BCLK/LRC） | 3 | SD 脚硬件接电平省 1 |
| 震动马达 PWM | 1 | MOS 驱动 |
| 电池电压 ADC | 1 | 分压 |
| View / Menu | 2 | |
| 充电状态输入（CH224K PG/BMS） | 1 | 屏显充电图标 |
| Boot（GPIO0 复用） | 1 | 兼用户键 |
| **合计** | **~24–27** | **余量 1–4 脚** |

**结论**：引脚满足但余量不奢侈——新按键走扩展芯片；重要扩展（图传）走 USB/连接器，不占 GPIO。

## 3. 电源树

```text
18650×2 串联 2S(7.4V) ──电源拨动开关──┬─▶ buck#1 5V  ─▶ 屏背光 / 对外供电预留(图传)
   └ BMS(均衡+过流+过放)            └─▶ buck#2 3.3V ─▶ S3/nRF24/ADS7830/PCA9555/MPU6050/MAX98357
Type-C ──CH224K PD诱骗(9V)──▶ 2S 8.4V CC/CV 充电
   └ D−/D+ ──▶ S3 原生 USB（数据；插电脑不充电）
分压电阻 ─▶ ADC ─▶ 电池电压遥测（屏显电量条+低电报警，遥测系统第一个本机数据）
```

| 设计点 | 说明 |
|---|---|
| 2S 串联 vs 并联 | buck 降压纹波小、PA 峰值电流余量足；并联需 buck-boost 且升压纹波灌射频——**串联定稿** |
| 充电 | Type-C PD 协商 9V（CH224K）→ 普通 2S 8.4V CC/CV；插电脑仅数据 |
| 电流裕量 | 3.3V 轨 ≥500mA，同时为升级 E01-2G4M27D（更高功率）预留 |

## 4. 反馈单元

| 单元 | 驱动 | 用途 |
|---|---|---|
| 震动马达 | GPIO PWM + MOS（200mA 级） | 低电报警、失控提示、游戏 |
| 扬声器（16Ω 小喇叭） | MAX98357A I2S | 提示音、游戏音效、WAV |

两者统一走 `feedback_event(id)` 事件服务分发。

## 5. 其余外设

| 外设 | 选型 | 说明 |
|---|---|---|
| 显示 | ~2" SPI IPS（ST7789 类） | **型号待定**；esp_lcd 驱动抽象，换屏只改驱动配置（分辨率/初始化序列/背光脚）；无触摸 |
| IMU | MPU6050 插拔模块座 | 引脚兼容 ICM-42688-P（候选：噪声低 5×、2KB FIFO），拔插即换 |
| 射频 | E01-ML01DP5 | Radio HAL；预留 E01-2G4M27D（SMA+焊接天线双封装，尺寸 ⚠ 待核对） |
