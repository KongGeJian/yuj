# yuj-common 模块规范（law.md）

> 只写本模块增补，总规范见 [docs/ai-coding/coding.md](../../../docs/ai-coding/coding.md)。

## 协议实现纪律

| 规定 | 说明 |
|---|---|
| 零平台依赖 | 禁止 include `esp_*` / `stm32f1xx_*` / FreeRTOS 等任何平台头——保证桌面可编译单测 |
| 不反向依赖 | 不得 include core/rx 任何文件；不得引用任何外部分配的硬件资源 |
| 帧格式唯一真源 | 帧字段/偏移量只在本库头文件定义一次（带注释），两端引用，**禁止手抄偏移量** |
| 版本 bump 纪律 | 帧格式任何改动 → bump `PROTOCOL_VERSION` + 双端同改 + 更新 `docs/protocol.md`，三者同一个 PR |
| Host 单测必配 | 帧编解码/跳频序列/边界值（如通道值钳制）必须有桌面单测，改协议先改测试 |
| 确定性 | 跳频序列由 (种子, 计数) 纯函数生成——**禁止随机数、禁止全局可变状态**（两端结果必须逐 bit 一致） |
