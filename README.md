# YUJ — 驭界

**YUJ（驭界）** 是一个面向多种遥控模型与扩展控制场景的开源硬件 / 软件项目，目标是探索一套模块化、可扩展的控制系统。

项目计划围绕遥控端与接收机展开，并逐步探索多种载具控制、遥测、图传及模拟器支持。具体功能、硬件方案与通信协议将随着设计和验证逐步确定。

> 项目仍处于开发与方案探索阶段。本文描述的是项目方向，不代表所有功能已经实现。

## 项目目标

- **多载具控制：** 面向 RC 汽车、飞机、船、坦克等模型。
- **模块化设计：** 将遥控端、接收机及后续扩展模块划分为相对独立的子项目。
- **可扩展能力：** 为遥测、图传、模拟器集成及其他功能预留演进空间。
- **文档驱动：** 记录设计方案、接口约定、测试结果、使用说明与开发决策。
- **开放协作：** 尽可能让设计过程、实现进度和已知限制清晰可见。

## 仓库结构

```text
yuj/
├── CLAUDE.md       # 项目统筹入口（概览 + 规范索引）
├── docs/           # 跨模块文档
│   ├── index.md          # 文档地图
│   ├── todo.md           # 待办事项
│   ├── architecture.md   # 系统架构、软件分层、UI/交互设计
│   ├── protocol.md       # 链路协议契约
│   ├── parts.md          # 元器件与成品模块选型库
│   ├── pcb.md            # PCB 设计要点
│   ├── datasheet/        # 元件数据手册/规格书（文件名 = 型号）
│   └── ai-coding/law.md  # 项目总规范（代码/架构铁律/Git/文档）
├── yuj-common/     # 链路协议公共库（两固件共享，纯源码）
├── yuj-core/       # 遥控终端固件（ESP32-S3, ESP-IDF + LVGL）
└── yuj-rx/         # 接收机固件（STM32F103, CMake）
```

### `docs/` — 项目文档

跨模块内容：系统架构与 UI 设计、链路协议契约、元器件选型库（`parts.md`）、PCB 设计要点、待办事项；`datasheet/` 存元件数据手册；`ai-coding/law.md` 为开发总规范。模块独有的设计文档与规范在各 `yuj-x/docs/` 内。

### `yuj-rx/` — 接收机

接收机侧子项目，负责接收来自遥控端的控制数据，并按最终确定的硬件与协议方案输出控制信号或与其他模块交互。

具体支持的输出接口、通道数量、链路协议及安全机制，以子项目文档和实际实现为准。

## 设计原则

1. **先明确接口，再推进实现：** 记录模块之间的接口、数据格式和依赖关系。
2. **安全优先：** 设计并验证失联处理、输出默认状态、上电行为和故障恢复机制。
3. **逐步验证：** 从最小可用链路开始，经过台架测试后再进行实际模型测试。
4. **文档与代码同步：** 重要的设计变更、兼容性影响和已知问题应记录在文档中。

## 参与开发

欢迎提交问题、设计建议和改进意见。提交代码或硬件方案前，建议先阅读 `docs/` 中的相关设计文档，并在 Issue 或 Pull Request 中说明：

- 测试环境与验证结果
- 对现有接口或兼容性的影响

## 安全说明

本项目面向模型控制与实验用途。请在安全、合法且可控的环境中测试。实际运行前，应验证失联保护、控制输出、供电和射频配置，并遵守所在地适用的无线电及飞行法规。
