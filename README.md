# YUJ（驭界）

**YUJ（驭界）** 是一个面向多种遥控模型与扩展控制场景的开源硬件 / 软件项目，目标是探索一套模块化、可扩展的控制系统。

项目计划围绕遥控端与接收机展开，并逐步探索多种载具控制、遥测、图传及模拟器支持。具体功能、硬件方案与通信协议将随着设计和验证逐步确定。

> 项目仍处于开发与方案探索阶段。本文描述的是项目方向，不代表所有功能已经实现。

## 项目目标

- **多载具控制：** 面向 RC 汽车、飞机、船、坦克等模型。
- **模块化设计：** 将遥控端、接收机及后续扩展模块划分为相对独立的子项目。
- **可扩展能力：** 为遥测、图传、模拟器集成及其他功能预留演进空间。
- **文档驱动：** 记录设计方案、接口约定、测试结果、使用说明与开发决策。
- **开放协作：** 尽可能让设计过程、实现进度和已知限制清晰可见。

### 遥控终端 - `yuj-core/`

ESP32-S3（N16R8）+ ESP-IDF + LVGL。**链路主站**（TDMA 节拍发起方）+ UI/交互中枢。

- 硬件：2S 18650 + PD 诱骗充电、2.4" SPI IPS 屏（240×320）、双摇杆+旋钮（ADS7828 外置 ADC 采集）、14 按键 + 4 拨杆（PCA9555 扩展）、震动马达 + I2S 音频反馈、MPU6050 插拔座
- 软件：应用/服务/HAL 三层架构、A/B 双模式主界面、模型管理（模板→实例两级抽象）、双分区 OTA
- 硬件详设：[docs/pcb.md](./docs/pcb.md) §2
- 架构与 UI：[docs/architecture.md](./docs/architecture.md)

### 接收机 - `yuj-rx/`

STM32F103C8T6 裸机固件（CMake + arm-none-eabi-gcc）。**链路从站**（TDMA 应答方）。

- 8 通道 PWM 输出（50/333Hz 可配）、串口×2（飞控 / GPS 遥测回传）
- 双模供电（舵机轨取电 / 2S 直供）、LED 状态灯 + 独立绑定键、failsafe 失控保护
- 原型：Blue Pill + E01 模块，先于整机板验证链路
- 硬件详设：[docs/pcb.md](./docs/pcb.md) §3

## 设计原则

1. **先明确接口，再推进实现：** 记录模块之间的接口、数据格式和依赖关系。
2. **安全优先：** 设计并验证失联处理、输出默认状态、上电行为和故障恢复机制。
3. **逐步验证：** 从最小可用链路开始，经过台架测试后再进行实际模型测试。
4. **文档与代码同步：** 重要的设计变更、兼容性影响和已知问题应记录在文档中。
