# yuj-rx 模块规范（law.md）

> 只写本模块增补，总规范见 [docs/ai-coding/coding.md](../../../docs/ai-coding/coding.md)。

## 裸机架构（前后台）

| 规定 | 说明 |
|---|---|
| 结构 | 主循环（后台）+ 中断（前台）；**无 RTOS**——20KB RAM 与确定性优先 |
| 前台纪律 | ISR 只置标志/写缓冲/更新捕获值，**禁阻塞禁打印**，快进快出 |
| 共享变量 | ISR 与主循环共享的一律 `volatile` + 临界区（`__disable_irq()` 短临界）保护 |
| 看门狗 | IWDG 必开；主循环喂狗位置即「系统存活」语义 |

## PWM 输出（定时器）

| 规定 | 说明 |
|---|---|
| 通道 | 8× 独立 PWM，50/333Hz 可配，1000–2000µs 脉宽 |
| 实现 | 定时器硬件 PWM（无软件 bit-bang）；通道值更新走预装载影子寄存器，**同帧原子生效**，杜绝半新半旧 |
| 更新时机 | 收到控制帧 → 立即更新（协议 t=0 语义），不等主循环轮询 |

## 链路时序

| 规定 | 说明 |
|---|---|
| 应答窗口 | 遥测帧在收到控制帧后的**固定窗口**内发出（协议 t≈0.5ms），从 SPI 到射频发射全程不用 malloc |
| failsafe | 500ms（可配）无有效帧 → 输出预设值；判定放定时器中断计数，不依赖主循环健康 |
| 上电 | 未收到有效信号前**不输出** |

## Flash 保存

| 规定 | 说明 |
|---|---|
| 内容 | 绑定信息（地址+跳频种子）、failsafe 配置（遥控端下发，跟模型走） |
| 位置 | Flash **末页**专用，与固件镜像隔离 |
| 写入策略 | 只在配置变化时写入 + 简单磨损均衡（环形槽位），**禁止每个链路周期写 flash** |
| 结构 | 数据带 magic + CRC + 版本，坏则丢弃回默认安全值 |
