# yuj-rx 接收机硬件详设

> 选型依据见 [../../docs/parts.md](../../docs/parts.md)；PCB 布局与红线见 [../../docs/pcb.md](../../docs/pcb.md) §3。

## 1. 双模供电

```text
模式A(舵机轨取电)                     模式B(电池直供，大功率)
信号排针 VCC ──肖特基──┐            2S电池专用接口 ──反接二极管+自恢复保险──▶ BEC(buck 5V)
 (4.0–5.5V)            ├────── 肖特基合流 ──▶ LDO 3.3V ──▶ nRF24/STM32
                       ┘
```

| 设计点 | 说明 |
|---|---|
| 模式A | 舵机轨 VCC 兼作电源输入（标准接收机行为：插任一通道排针 V/G 供电，全板 VCC 连通） |
| 合流 | 两路肖特基合流进 LDO，**可同时接互不倒灌**（调试场景） |
| 模式B 边界 | **BEC 只供内部，不反灌舵机 VCC 针**——大功率场景舵机由外部 BEC 各自供电（⚠ 红线：2S 直入 5V 舵机 = 烧毁） |
| BEC / LDO | BEC 宽输入 buck（Vin≥17V 裕量，5V/1A）；LDO 3.3V ≥300mA（nRF24 PA 峰值 ~130mA + STM32） |

## 2. LED（2× 0603）

| LED | 颜色 | 语义 |
|---|---|---|
| PWR | 绿 | 常亮=上电 |
| LINK | 蓝 | 慢闪(1Hz)=搜寻 / 常亮=链路锁定 / 快闪(5Hz)=绑定模式 / 双闪循环=failsafe 生效中 |

## 3. 输出接口

| 接口 | 规格 |
|---|---|
| PWM 排针 | **8× 三线组（GND/VCC/SIG）**，SIG 靠边；1000–2000µs，50/333Hz 可配 |
| 串口×2 | UART1：飞控（CRSF/SBUS 类，双向）；UART2：GPS 等模块（遥测回传，链路分片轮播） |
| 天线 | E01 模块自带（SMA/IPEX），净空见 pcb.md §1 |

## 4. 其余

| 项 | 设计 |
|---|---|
| 绑定键 | 独立按键，靠近 LED；上电 5s 内按住进配对 |
| 主控 | STM32F103C8T6；RAM 不够升 CBT6/RCT6，架构不变 |
| 未来 10–16ch 板 | 同架构：通道数据结构 + 输出映射表参数化，协议 16ch 字段已预留，换高引脚型号即可 |
